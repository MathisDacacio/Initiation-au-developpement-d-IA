## Description du projet

Ce projet consiste en l'initiation au développement d'une intelligence artificielle (IA) capable d'estimer le prix d'une voiture en fonction de ses caractéristiques, telles que le modèle de la voiture et son kilométrage. Pour ce faire, un fichier CSV complet est utilisé pour entraîner l'IA à faire des prédictions basées sur les données de ce fichier.

L'objectif de ce projet est de comprendre les bases de l'apprentissage supervisé et de l'utilisation de bibliothèques Python populaires pour la manipulation de données (comme Pandas) et l'entraînement de modèles d'IA (comme Scikit-learn).

## Fonctionnalités

- **Lecture d'un fichier CSV** : Le projet commence par la lecture d'un fichier CSV contenant des informations sur les voitures, comme le modèle et le kilométrage.
- **Entraînement d'une IA** : Un modèle d'IA est entraîné pour prédire le prix d'une voiture en fonction de ces informations.
- **Prédiction du prix** : Une fois le modèle entraîné, il est utilisé pour estimer le prix d'autres voitures en fonction de leurs caractéristiques.

## Prérequis

- **Python** (version 3.7 ou supérieure)
- Bibliothèques Python nécessaires :
  - `pandas` : Pour la manipulation et l'analyse des données.
  - `scikit-learn` : Pour la création et l'entraînement du modèle d'IA.
  - `matplotlib` : Pour la visualisation des résultats (optionnel).

## Installation

1. Clonez le projet ou téléchargez les fichiers nécessaires.
2. Créez un environnement virtuel (optionnel) et installez les dépendances :
    ```bash
    pip install -r requirements.txt
    ```
3. Placez le fichier CSV dans le répertoire approprié (ou mettez à jour le chemin du fichier dans le code).

## Comment utiliser le projet

1. Lancez le script Python qui lit le fichier CSV et entraîne le modèle d'IA.
2. Le modèle est entraîné sur les données du fichier CSV et peut ensuite être utilisé pour prédire le prix d'une voiture donnée en fonction de son modèle et de son kilométrage.
3. Si vous souhaitez tester le modèle sur de nouvelles données, fournissez les informations de la voiture (par exemple, le modèle et le kilométrage) et le modèle vous renverra une estimation du prix.
